qual a formula da area de um triangulo
A fórmula geral para calcular a área de qualquer triângulo é A=2b⋅h​, onde **b** é a medida da base e **h** é a medida da altura perpendicular a essa base. 

Existem outras fórmulas dependendo dos dados disponíveis:

- **Triângulo Retângulo**: Quando conhecidos os dois catetos ( a e b ), a área é A=2a⋅b​.
    
- **Fórmula de Heron**: Quando conhecidos os três lados ( a, b e c ), calcula-se o semiperímetro s=2a+b+c​ e a área é A=s(s−a)(s−b)(s−c)​.
    
- **Trigonometria**: Quando conhecidos dois lados ( b e c ) e o ângulo entre eles ( A ), a área é A=2b⋅c⋅sin(A)​.
